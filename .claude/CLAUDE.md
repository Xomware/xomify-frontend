# xomify-frontend

> Spotify companion app — playlist builder, listening stats, release radar.

## What This Is
Angular SPA frontend for Xomify. Connects to the Xomify backend for Spotify data.

## Stack
- Angular 18, TypeScript, SCSS

## Key Commands
```bash
npm start           # dev server
npm run build:prod  # production build
npm test            # unit tests
```
